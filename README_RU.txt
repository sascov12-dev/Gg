КАК ПОЛУЧИТЬ IPA БЕЗ MAC:
1. Создай пустой репозиторий на GitHub.
2. Загрузи в него ВСЁ содержимое этой папки, включая скрытую папку .github.
3. Открой вкладку Actions -> Build unsigned IPA -> Run workflow.
4. После завершения открой запуск и скачай Artifact: MinimalClicker-unsigned-ipa.
5. Внутри будет MinimalClicker-unsigned.ipa.
6. Подпиши этот IPA своим .p12 + .mobileprovision в ESign/Feather.

ВАЖНО:
IPA специально создаётся БЕЗ подписи. Это нормально: его нужно подписать твоим сертификатом перед установкой на iPhone.
